# Code of Conduct

## The short version

Be straight, be useful, and assume the other person is acting in good faith. Technical disagreement is welcome — including "this design is wrong, here is why" — as long as it stays about the work.

Not welcome: harassment, insults, slurs, sexualized attention, deliberate intimidation, doxxing, or sustained disruption of an issue or discussion.

## Scope

Issues, pull requests, discussions, commit messages, and any space where someone is representing this project.

## Reporting and enforcement

Report a problem to the maintainer (`@Xio-Shark`). If the report is sensitive and you would rather not post it publicly, use the private channel described in [SECURITY.md](./SECURITY.md) — that reaches the same person without a public trail.

Reports are read in good faith and kept as private as the situation allows. What happens next depends on severity and pattern: a clarifying reply, a warning, hiding a comment, or a permanent ban from the project's spaces. Maintainers who cannot stay impartial on a given report will say so rather than pretend otherwise.

This is a small project with a single maintainer, so there is no committee and no guaranteed response time. There is only a commitment to not look away.
