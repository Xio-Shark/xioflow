## 覆盖范围

这次扩展把以下检查放进同一个真实循环：

- ISA `executePipeline` 的 `fs.write`：每轮执行一次，使用真实 `dist/isa` validator/pipeline 和异步 filesystem executor。
- crash/reopen：每 20 轮启动 SIGKILL worker，重新打开同一个 crash domain，确认 agent 为 `interrupted` 且不 replay。
- artifact prune：每轮登记一个已结束、已过期的 artifact，调用 `domain.pruneArtifacts` 并验证同一 inode 被删除。
- lease：每轮通过两个 agent 争用 `exclusive`，取消后检查 lease 已释放；同时统计 `leaseLeaks`。
- journal：每 5 轮在 `interrupt_requested` 边界注入一次异常，确认 parent 被中断而 child 不被错误传播。
- RSS、active handle 数、event-loop p99/max、journal/database 增长和残留 PID。

## 24 小时与 7 天入口

脚本支持两个显式目标 profile。先跑完 24 小时并检查报告，再启动 7 天；二者不应同时启动在同一个 domain 上：

```bash
pnpm build
XIOFLOW_SOAK_PROFILE=24h XIOFLOW_SOAK_OUTPUT=audit/results/isa-soak-24h.json node scripts/agent-soak.mjs
# 24h 报告 status=PASS 且 completedTargetDuration=true 后再运行：
XIOFLOW_SOAK_PROFILE=7d XIOFLOW_SOAK_OUTPUT=audit/results/isa-soak-7d.json node scripts/agent-soak.mjs
```

本次会话只完成了 5 秒短跑和 profile 参数 smoke；24 小时/7 天的真实运行尚未完成，不能据此宣称长期无泄漏或 Gate 3 已通过。`XIOFLOW_SOAK_SECONDS` 可用于验证 profile 字段，但缩短后的运行会保持 `completedTargetDuration=false`。
