# 自然语言任务与独立检查器

RFC-SI-003 · layer:research · 2026-11-03。

## 本轮目标

将“给定正确查询的机制实验”推进为可接入 Agent 的任务环境。任务只公开自然语言目标、源数据含义、回答格式与接口说明；正确过滤条件、参考答案和检查器状态不进入观察接口。本轮实现和验证环境，不将参考脚本的成功率当作模型能力。

## 任务与数据

六类任务各有一个开发实例和一个保留实例：多条件对象定位、集合完整性与计数、真实 ISA 注册表查询、长日志中最后一次失败诊断、区分缺失/null/空字符串、更新后的当前状态。服务和日志是临时文件中的合成数据，不冒充真实运行服务。注册表来自仓库文件的只读副本，并记录原始内容哈希。

开发任务用于接口调试；保留任务对未来模型运行保留，不把构造者可见的本地任务称作外部盲测。每轮保存语料、宿主和检查器源码哈希，修改后需要明确记录版本。

## 三组接口

- full：读取整个快照。
- jq：真实 jq 进程对同一快照的记录数组执行调用方给出的程序。
- structured：复用已有条件查询、完整行分页、文本展开。

三组都有相同的 describe、refresh、工具说明和提交格式。没有写接口。默认结果预算为 2,048 B，可显式增大至 65,536 B；full/jq 同样检查预算，超出时显式失败，不截断。预算约束结果体；轨迹计入完整请求/响应及初始任务说明。该协议只提供可调整预算条件，不声称已经完成固定预算与可调整预算的模型对照。

字节指标按 JSON 重新序列化后的完整消息计算，不含 JSONL 行分隔符；非法 JSON 请求按原始行字节计算。不是 tokenizer 结果、模型上下文或网络传输计费值。开发参考客户端为 full/jq 请求 65,536 B、为 structured 请求 2,048 B 并继续分页；这些是公开记录的固定策略，不能据其字节差异推断接口本身或真实模型优劣。

jq 有执行超时与输出上限，不继承宿主凭证环境；这是本地研究接口，不是面向任意恶意程序的安全沙箱。观察接口能力差异（例如 jq 聚合与结构化组客户端聚合）应记录，不能全部归因于表示格式。

## 终局检查

提交 `{version, answer}`。检查器独立读取源文件、计算内容哈希、按任务语义求值；不调用 FileObservation、jq 或参考客户端。当前版本必须来自该轮的数据观察。答案中的集合要求完整，无重复，不接受只找出一个例子。

每轮只有一次终局提交，不向中间查询返回正确答案或评分提示。无提交、非法答案、错误对象、遗漏、重复、旧版本和预算/工具错误都保留在轨迹中。

更新任务在首次成功的数据观察之后替换源文件；三组触发规则一致，任务明确要求重新获取快照。此调度用于检验观察版本与刷新，不代表真实异步系统的时延或竞态覆盖。

## 验证与边界

先运行已知正确的确定性客户端证明任务可完成，再注入错误答案证明检查器拒绝它们。参考客户端知道任务语义，故这些运行只证明可达性与检查器行为。

真实模型对照仍需固定端点、模型版本、指令、费用上限、重复和交错顺序。当前不自动发起收费调用。下一阶段再接入关注条件与等待：错误订阅、漏报、新鲜度、发现延迟和系统开销需联合衡量。
