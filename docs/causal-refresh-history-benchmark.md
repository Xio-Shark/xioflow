# 历史预测的独立时间验证基准

运行 `pnpm benchmark:refresh-history [hashRounds]`（默认 1000）输出 JSON；[样例报告](benchmarks/causal-refresh-history.sample.json) 来自真实文件工具、journal 和 OCC 提交。此基准复用七模式刷新基准的文件夹具：两个独立输入、一个共享观测以及两个派生输出。

协议在运行前固定训练扰动 `[0,1,0,1]` 和评估扰动 `[0,1,2]`，数字表示变化的独立输入数。每次执行从相同初始文件创建新工作区。训练使用强制探测，完成后冻结 `trainingAtSeq`，调用生产 API `estimateWorkspaceCausalRefreshHistory` 得到历史预测。每节点 execute / reuse / replay 成本也只从该训练窗口的实际回调耗时和工具次数估计；复用校验的一个批次回调按实际工具次数摊分。

强制探测用零成本先验确保选择 probe；这类样本的 `expectedCallbackCostMs: 0` 仅是控制策略的哨兵值，预测误差应读 `estimate.evaluation`。训练时使用每节点单位成本，评估时使用训练校准后的毫秒成本，因而变化后的增量/完整重算选择也可能不同。

每个评估任务分别运行独立强制探测、历史预测策略与固定静态先验策略。两种策略交替执行次序，使用同一个训练所得成本模型、相同扰动与哈希负载。静态先验在采样前固定，默认变化概率 0.5、探测条件成本各 1ms、变化后刷新成本 2ms；这是可审查的示例先验，不是有代表性的生产预测。程序接口 `runCausalRefreshHistoryBenchmark` 支持自定义先验和两组扰动；训练必须包含无变化和局部变化，才能校准复用成本。

独立探测任务按 `independent-probe` 聚合；策略任务使用独立标签，绝不混入训练或时间验证集。这样直接重算策略不会因缺少变化标签而把难例从验证集排除。`estimate.evaluation` 报告独立探测的成本 MAE，`samples` 保留每种策略的预测成本、实际回调毫秒、端到端毫秒、工具次数、输出哈希及决策/遥测序号。`summary` 对照成功率和平均实测成本；`trainingElapsedMs` 和 `trainingToolCalls` 单独列出学习开销，未摊入评估成本。报告序号仅在此次临时 journal 内有意义，结束后夹具回收。

所有发布仍强制完整观测重放；无变化探测保留快路径。正确性以直接计算的当前输入结果核验，不能用策略自行声称成功替代。计时不包含初始夹具构建和最终输出核对，包含刷新工作区、探测、修复、提交和回收；回调计时不包含这些工作区固定开销。

这是一项可复现协议的微基准，耗时及据此作出的策略选择随机器负载变化。统一每节点成本忽略读写工具的异质性，训练和评估的变化分布也可能不同；独立探测仅消除本基准内由策略选择造成的标签缺失，不能证明生产泛化或必然收益。`modelTokens: null`，没有真实模型 token 节省结论。

此次样例的三组策略正确率均为 100%；历史/静态策略平均回调耗时分别为 3.603/3.286ms，端到端耗时分别为 190.818/201.524ms。两种口径排序相反，不能据此声称历史策略全面更优；独立探测成本 MAE 为 0.841ms，仅有三个评估任务。
